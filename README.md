# Th1rdPlanet Task Hub

Единая точка входа для идей, ошибок и изменений проектов организации Th1rdPlanet.

Не нужно заранее знать, относится запрос к eSCore, сборке, прокси или сайту. Опишите результат или проблему — ревьювер уточнит детали и направит работу в нужный репозиторий.

## Создать запрос

- [Выбрать форму](https://github.com/Th1rdPlanet/task-hub/issues/new/choose)
- [Посмотреть открытые запросы](https://github.com/Th1rdPlanet/task-hub/issues)
- [Открыть Development Hub](https://github.com/orgs/Th1rdPlanet/projects/1)

## Правила

- Не публикуйте пароли, токены, приватные ключи, персональные данные и закрытые логи.
- Для уязвимостей используйте [приватный security report](https://github.com/Th1rdPlanet/task-hub/security/advisories/new).
- Технический процесс описан в [docs/workflow.md](docs/workflow.md).
