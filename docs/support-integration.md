# Future support integration

Интеграция саппорта создаёт issue только в `task-hub` и не распределяет его напрямую в репозиторий исходников.

## Контракт

Обязательные данные:

- внешний идентификатор тикета;
- очищенный заголовок и описание;
- шаги воспроизведения, если известны;
- затронутая функция или сервис;
- закрытая ссылка на тикет для авторизованных сотрудников.

## Безопасность и надёжность

- Идемпотентность определяется внешним идентификатором тикета.
- API-токены хранятся только на сервере или в GitHub Secrets.
- Email, IP, session tokens, приватные логи и иные персональные данные удаляются до создания публичного issue.
- Импорт получает метку `source:support` и попадает в Inbox.
- Создание ограничивается rate limit и журналируется.
- На первом этапе синхронизация односторонняя: support → GitHub, без обратного обновления статуса.

Реализация API не входит в первоначальный запуск Development Hub.
