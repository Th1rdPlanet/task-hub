# Схема Development Hub

Project: [Th1rdPlanet — Development Hub](https://github.com/orgs/Th1rdPlanet/projects/1)

## Status

`Inbox`, `Triage`, `Ready`, `In Progress`, `Review`, `Ready for Verification`, `Done`, `Deferred`, `Rejected`.

## Пользовательские поля

- **Приоритет:** High, Medium, Low.
- **Направление:** eSCore, Assembly, Proxy, Сайт, Инфраструктура, Несколько репозиториев, Не определено.
- **Тип:** Идея, Баг, Задача, Исследование, Миграция.
- **Ответственная команда:** Triage, Core, Assembly, Proxy, Web, QA.
- **Вид изменения:** Только конфиг, Обновить зависимость, Исправить существующий код, Заменить сторонний плагин, Создать свой плагин, Изменение Core, Изменение Proxy, Не применимо.
- **Целевой релиз:** свободный текст.
- **Причина решения:** объяснение для отклонённой задачи; свободный текст.

## Связанные репозитории

`task-hub`, `eSCore`, `ExiledAssembly`, `ExiledProxyBuild`, `newera-sync`, `thenewera`.

## Основные представления

- `Разбор` сгруппирован по полю `Направление`.
- `К выполнению` и `По репозиториям` сгруппированы по `Repository`.
- Доски разработки сгруппированы по `Status`.
- `Сборка и проверка` показывает работу направления `Assembly`.
- `Ожидает проверки` отдельно показывает все задачи в `Ready for Verification`, включая другие направления.
- `Отклонённые` показывает задачи в `Rejected` вместе с полем `Причина решения`.
