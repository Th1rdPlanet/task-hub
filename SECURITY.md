# Security

Не публикуйте сведения об уязвимостях, токены, ключи, персональные данные или приватные логи в обычных issues.

Отправьте сведения через [GitHub Private Vulnerability Reporting](https://github.com/Th1rdPlanet/task-hub/security/advisories/new). Укажите затронутый компонент, влияние и безопасные шаги воспроизведения.
